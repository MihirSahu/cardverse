# Cardverse candidate card catalog

Working source-of-truth for the first manually curated Cardverse catalog. This file is intended to be refined, reviewed, and then converted into database seed data.

Last reviewed from issuer catalog appshots: **2026-08-05**

## Scope rules

- Include currently advertised U.S. personal/consumer credit and charge cards.
- Include general-purpose student and secured cards.
- Exclude business and commercial cards.
- Exclude co-branded and establishment-specific cards, including airline, hotel, retailer, telecom, warehouse-club, and travel-booking partner cards.
- Keep materially different underwriting variants as separate rows when fees, welcome offers, or eligibility differ.
- A direct artwork URL must point to the card image itself, not a product page. All included rows now have issuer-hosted artwork URLs collected from the issuer pages.
- Offers and APRs change frequently. Every value below should retain a `source_checked_at` value when moved into the database.

## Proposed database fields

`id`, `name`, `issuer`, `audience`, `category`, `annual_fee`, `welcome_offer`, `rewards_summary`, `intro_apr`, `network`, `product_url`, `image_url`, `source_checked_at`, `review_status`
